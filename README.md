# اطلس تجهیزات پزشکی

یه منبع آموزشی رایگان برای دانشجویان مهندسی پزشکی.

## درباره پروژه
اطلس تجهیزات پزشکی شامل معرفی دستگاه‌های پزشکی به همراه ۹ بخش علمی برای هر دستگاهه:
- اصل کارکرد
- اجزای اصلی
- کاربرد بالینی
- مشخصات فنی
- استانداردها و کلاس خطر
- ایمنی و هشدارها
- خرابی‌های رایج و عیب‌یابی
- نگهداری و کالیبراسیون
- سوالات خودآزمایی
